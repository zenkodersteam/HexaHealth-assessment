# Assessment Submission

Two independent projects for the frontend and backend assessments.

- [`frontend-landing/`](frontend-landing) — Responsive product landing page (Next.js + TypeScript).
- [`backend-notes-api/`](backend-notes-api) — Notes CRUD REST API (NestJS) with an in-memory store and a demo HTML frontend.

Each project has its own README with setup/run instructions.

## Quick start

```bash
# Frontend — http://localhost:3000
cd frontend-landing
npm install
npm run dev

# Backend — http://localhost:3001
cd backend-notes-api
npm install
npm run start:dev
```
